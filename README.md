# Personal Expense Tracker (CLI)

This is a personal project built to manage daily income and expenses directly via the command line (Command Line Interface), using Python and an SQLite database.

## Key Features
- **Add Transaction:** Record the amount and categorize it using custom categories.
- **View History:** Display the full list of saved expenses.
- **Filter & Statistics:** Look up details by specific category and automatically calculate the total amount.

## Technologies Used
- Language: Python 3.13 or later
- Database: SQLite3 (built-in)

## Installation & Execution Guide
1. Make sure Python is installed on your computer.
2. Download the project source code to your machine.
3. Open the terminal/cmd in the directory containing the source code and run the command:
   ```bash
   python app.py
